# ytt-subject-editor
.ytt 자막의 효과를 작업할 수 있는 에디터입니다

## 다운로드
[다운로드](https://github.com/Area-01/ytt-subject-editor/raw/refs/heads/main/YTT-%ED%8E%B8%EC%A7%91%EA%B8%B0(v0.2).zip)

## 알려진 버그
에디터에서 글꼴을 선택했을 때 영어에만 글꼴 변화가 적용되지만
실제로 유튜브에 자막을 넣었을 때는 선택한 글꼴에 따라 한글 글꼴이 변경됩니다

에디터에서 보이는 것과 같은 형태의 한글 글꼴을 유튜브에서도 보려면 '비례 고딕' 글꼴을 선택하셔야 합니다
